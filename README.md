# SZARA

Static HTML/CSS/JavaScript business website for SZARA / withszara.com.

- `/index.html`: BUILD / GROW / RUN services, selected real work and contact.
- `/small-business-websites/index.html`: website-and-care offer, scope and FAQ.
- `/assets/style.css`: shared responsive design, including layered project previews.
- `/assets/site.js`: client-side email brief preparation; no server submission.

No build or dependencies are required. Serve this directory with any static HTTP server. All asset and internal links are relative so the site works both under `/Backef/` and at a custom-domain root.

## Contact and launch status

The domain withszara.com is live. Both forms submit directly to FormSubmit at hello@withszara.com, with native validation and the provider spam check. Cloudflare forwards incoming mail to the owner's verified Gmail address. The owner confirmed enquiry receipt and the thank-you redirect on 2026-09-26. Outgoing domain email is a separate setup and is not yet configured.

Enquiry source context includes the current page path, optional how-you-found-us answer and allowlisted campaign labels (utm_source, utm_medium, utm_campaign). Labels accept only letters, digits, underscores and hyphens, up to 80 characters. No cookies, local/session storage, full referrer URLs, click identifiers or third-party analytics are added. Campaign labels are carried between internal home and offer links. Do not put customer identifiers in campaign labels.

This records source information in received enquiry emails; it is not an ad-platform conversion integration. A submit click or thank-you page visit is not counted as proof of delivery. No ads launched.
